# Перенос секции поддержки и обновление кеша

## Цель

Сделать поддержку заметной сразу после первого экрана и исключить повторение
ситуации, когда новый HTML GitHub Pages отображается со старым CSS.

## Порядок страницы

Секции располагаются так: главный экран → поддержка → проверенные игры → «Как
это работает» → остальные информационные разделы. Основной CTA «Скачать»
остаётся первым действием страницы и не конкурирует с донатом внутри hero.

Секция поддержки переносится целиком. Её заголовок, вкладки CloudTips,
«Криптовалюта» и «Карта», реквизиты и логика копирования не изменяются. Ссылка
`#support` в навигации продолжает вести к той же секции.

## Кеш статических ресурсов

Ссылки на `assets/styles.css` и `assets/site.js` получают одинаковый параметр
версии. При публикации браузер запрашивает новые URL и не применяет старые стили
к обновлённой разметке. Автоматическая проверка сайта требует версию у обоих
ресурсов.

## Проверка

- `scripts/check_site.py` проходит.
- В опубликованном HTML секция `support` находится между `top` и `games`.
- Production CSS содержит стили вкладок, а HTML подключает версионированный CSS.
- На широком и мобильном экране вкладки и реквизиты не выходят за карточку.
