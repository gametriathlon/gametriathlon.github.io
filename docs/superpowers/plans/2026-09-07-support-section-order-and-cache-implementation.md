# План переноса секции поддержки

1. Дополнить `check_site.py` проверкой порядка `top → support → games` и
   обязательного cache-busting для CSS/JS.
2. Переместить существующую секцию `support` сразу после hero без изменения её
   содержимого и реквизитов.
3. Запустить проверку сайта, проверить desktop/mobile и отсутствие ошибок JS.
4. Закоммитить и отправить исправление в `origin/main`, затем проверить
   опубликованные HTML и CSS.
