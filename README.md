# gametriathlon.github.io

Сайт и релизы проекта **Game Triathlon** — открытой обёртки для запуска
Lesta Game Center и его игр на Mac с Apple Silicon.

Исходные тексты приложения живут в отдельном репозитории; здесь только
страница и собранные образы.

## Что где

```
index.html      лендинг
licenses.html   лицензии компонентов и предложение исходных текстов (LGPL/GPL)
styles.css      оформление, один файл, без сборщика
assets/         иконка и скриншоты
```

Сборщика нет намеренно: страница статическая, зависимостей у неё нет, и
любая правка видна сразу — достаточно открыть `index.html` в браузере.

## Как опубликовать

GitHub Pages включается в настройках репозитория: **Settings → Pages →
Source: Deploy from a branch → main / (root)**. Через минуту страница
открывается по адресу `https://gametriathlon.github.io`.

## Релизы

DMG выкладывается сюда же, в Releases. Так раздача не стоит нам ни хостинга,
ни трафика, а ссылка на странице ведёт на `/releases/latest` и не требует
правок при каждом выпуске.

При выпуске новой версии не забыть про раздел «Что нового» в `index.html`:
он заполняется руками.

## Локальный просмотр

```bash
python3 -m http.server 8000
```

Затем открыть http://localhost:8000.
